# Folder Summary

- `.CLAUDE.md.swp` — Vim swap file left over from editing `CLAUDE.md`.
- `.DS_Store` — macOS Finder metadata file.
- `.env.development` — Environment variables used during local development.
- `.env.production` — Environment variables used for the production build (includes `VITE_API_BASE`).
- `.eslintrc.json` — Legacy ESLint configuration.
- `.git/` — Git repository metadata and history.
- `.gitignore` — Patterns for files/folders excluded from git tracking.
- `.prettierrc` — Prettier code formatting configuration.
- `.vite/` — Vite's local cache directory.
- `.vscode/` — VS Code editor/workspace settings.
- `CLAUDE.md` — Project guidance and architecture notes for Claude Code.
- `README.md` — Project overview and setup instructions.
- `dist/` — Production build output generated by Vite.
- `eslint.config.js` — Modern flat-config ESLint configuration.
- `index.html` — Vite's HTML entry point for the app.
- `package-lock.json` — Locked dependency versions for reproducible installs.
- `package.json` — Project metadata, scripts, and dependencies.
- `public/` — Static assets served as-is by Vite.
- `src/` — Application source code (React/TypeScript frontend).
- `tsconfig.app.json` — TypeScript configuration for the app source.
- `tsconfig.json` — Root TypeScript project-references configuration.
- `tsconfig.node.json` — TypeScript configuration for Node-side config files (e.g. `vite.config.ts`).
- `vite.config.ts` — Vite build/dev-server configuration, including backend proxy setup.
